## 4. デザイントークン

`assets/css/style.css` の `:root` に定義済み。**新しい色や余白を勝手に増やさない。**

```css
:root {
  --color-base:   #FFFFFF;
  --color-text:   #1A1A1A;
  --color-accent: #B1D035; 

  --font-heading: "游ゴシック体", sans-serif;
  --font-body:    "游ゴシック体", sans-serif;

  --space-sm: 8px;
  --space-md: 16px;
  --space-lg: 40px;
}
```

### 品質チェックリスト

デザイン確定前・仮アップ・本アップの3回、自分でチェックしたうえで別の目（AI・第三者）でもう一度確認する。
「いつ・誰が」のルールは CLAUDE.md 7章を参照。

#### ① デザイン確定前
- [ ] サイトの目的（優先順位）とファーストビューが合っている
- [ ] 問い合わせ・申込への導線が、各ページに1つ以上ある
- [ ] ブランドカラー・フォントが指定どおり
- [ ] スマホ幅のデザインを確認した
- [ ] 文字サイズ・行間・コントラストが読める範囲
- [ ] 原稿に誤字脱字・表記ゆれがない（会社名・電話番号・住所は原本と照合）

#### ② 仮アップ（テスト環境）
- [ ] SP / TB / PC で表示崩れがない
- [ ] 全リンクが正しい（リンク切れなし）
- [ ] フォームが送信でき、自動返信・管理者通知が届く
- [ ] 画像が圧縮されており、全画像に alt がある
- [ ] title / description / OGP が全ページ固有で設定されている
- [ ] ファビコンが設定されている
- [ ] 表示速度（PageSpeed Insights）を確認した

#### ③ 本アップ（公開直後）
- [ ] 本番 URL で全ページが表示される
- [ ] SSL（https）が有効
- [ ] GA4・GTM・Search Console が設定され、計測が動いている
- [ ] テスト用の noindex・Basic 認証を外した
- [ ] 本番フォームで送信テストをした
- [ ] サイトマップを Search Console に送信した
- [ ] バックアップを取った

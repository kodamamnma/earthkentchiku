# History

**新しい記録を上に積む（新しい順）。** エージェントは直近3件を読めば現状を把握できる状態を保つ。

記録形式:

```markdown
## YYYY-MM-DD

### [対象ファイル/機能]
- 工程:
- やったこと:
- なぜ:
- 影響範囲:
- 時間:
- 気づき:
```

## 気づきログ

案件中に気づいたことを、その場で1行書く。月1回、次の3つに分類してルールブックへ反映する。

- ルール: 品質チェックリスト（README.md 6章）に1行追加する
- 啓蒙: ルールはあるが意識が薄れている。テンプレートに注意書きを足す
- 注意: 今回だけの反省。この案件のログに残すだけにする
